# How to Run the Analysis

## Prerequisites

1. **Python 3.11 or higher** (recommended Python 3.14.3)
2. **Required libraries** listed in `requirements.txt`

## Installation

### 1. Create a virtual environment

```bash
# On macOS/Linux
python3 -m venv .venv
source .venv/bin/activate

# On Windows
python -m venv .venv
.venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

## Running the Analysis

### Del 1: Grundläggande analys och statistik

To run Del 1 analysis:

```bash
cd del1
python health_analysis_del1.py
```

This will:
- Perform descriptive statistics
- Generate 3 visualizations (histogram, boxplot, bar chart)
- Run disease prevalence simulation
- Calculate confidence intervals using 2 methods
- Perform hypothesis testing
- Conduct power analysis (VG)

All graphs will be saved to the `output/` directory.

## Reproducibility

The script uses:
- Fixed random seed: `np.random.seed(42)`
- Relative file paths: `../data/health_study_dataset.csv`
- Standard libraries that are easily installable

This ensures that results are reproducible when running the scripts.

- The `output/` directory is in `.gitignore` to avoid bloating the repository with generated images
